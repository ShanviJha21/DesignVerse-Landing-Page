# DesignVerse-Landing-Page
This is the landing page for a fictional design fest named DesignVerse.
Design fest are places where people can show thier best creativity and design.And who is a better designer than nature itself?
That is why taking inspiration from nature itself, the landing page follows a limitless sky like interface slowly transitioning to the endless universe.
